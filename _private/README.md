# Private working files (never published)

Put downloaded papers (PDFs) and anything else that must not go on the web in this folder when you work on the site with Claude Code on your own computer.

- Everything here except this README is git-ignored, so it is never committed or pushed.
- The folder is excluded from the Jekyll build, so it can never appear on the website.
- The repository is public. Do not remove the ignore rule, because anything committed here would be downloadable from GitHub.
- Cloud sessions start from a fresh clone and cannot see these files. In a cloud session, attach the PDFs to the chat instead.
